# Smart Attendance System Using OpenCV & Face Recognition

## Overview
An **AI-powered Smart Attendance System** developed using **Python, OpenCV, and Face Recognition** to automate student attendance through real-time facial identification. It reduces manual effort, saves time, and improves attendance management.

##  Key Features
- Real-time face detection and recognition
- Automatic attendance using a webcam
- Date and time-based attendance records
- Prevention of duplicate attendance
- Digital attendance tracking
- Fast, efficient, and user-friendly system

## Tech Stack
- **Language:** Python
- **Libraries:** OpenCV, Face Recognition, NumPy, Pandas
- **Data Storage:** CSV
- **Technology:** Artificial Intelligence & Computer Vision

## How It Works
1. Register students with their facial images.
2. Capture live video through a webcam.
3. Detect and recognize registered faces.
4. Automatically mark attendance with date and time.
5. Store attendance records digitally.
